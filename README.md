Training App is a web app where you sign up and sign in so your session keeps you logged in. Once you’re in, you can create, read, update, and delete workout entries (things like title, date, duration, focus, intensity, and notes) stored in MongoDB. Each workout is tied to your user account, so only you can see and change your own data.
